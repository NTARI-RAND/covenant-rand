# Tier 3: Rating and Adjudication in the Interface

*The goal of Tier 3 is to implement the covenant in the interfaces where people rate each other and settle disputes.*

An operator settles disputes between its own prosumers. Disputes that cross platforms, or involve the operator itself, go to the witnesses. Whoever settles a dispute is rated by its parties.
