# Tier 1: The Leveson-Based Trade Assessment Scale

*The goal of Tier 1 is to understand how a promise not to harm becomes a rating.*

LBTAS has six fixed-meaning levels from -1 to +4. Reputation is the count of exchanges at each level, never one number (JFA line 8), and decides whether to trade on trust, never how much (line 9).
